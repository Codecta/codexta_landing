01

Getting started

Four steps take you from install to a working assistant: install the app, choose a plan, switch on the app embed, and run the guided setup.

How do I install Codexta?

  • Who: the Shopify account owner
  • Plan: any
  1. Install Codexta from the Shopify App Store (see Codexta for Shopify) and approve the access Shopify asks for.
  2. Shopify opens Codexta in your admin. The Shopify account owner becomes the Owner in Codexta.
  3. Choose a plan (next task). Until you do, the assistant does not answer shoppers.

How do I choose a plan and start the trial?

  • Who: Owner
  • Plan: Lite, Start, Growth or Scale

Shopify admin › Apps › Codexta › Settings › Plan

  1. When you first open Codexta without a plan, it sends you to Shopify’s plan page. You can also press Choose a plan in the banner at the top of every page.
  2. Pick Lite, Start, Growth or Scale and approve it in Shopify. The free trial, if shown there, starts when you approve.
  3. Shopify brings you back to Codexta. Settings › Plan now shows your plan and its status.

Until a plan is approved, every page shows the banner Choose a plan to switch the assistant on. Colleagues who are not the owner see Ask the store owner to choose a plan. Shoppers who open the chat meanwhile read:

SHOPPERS SEEThis assistant is not active yet. Please use another way to get in touch for now.

How do I show the assistant on my storefront?

  • Who: Owner, Admin (the setup card is shown to them)
  • Plan: any

Shopify admin › Apps › Codexta › Overview › Set up your assistant

  1. Under Show the assistant on your storefront., press Open the theme editor. The theme editor opens in a new tab.
  2. Check that Codexta assistant is switched on under App embeds.
  3. Press Save.

Without the card: Shopify admin › Online Store › Themes › Customize › App embeds › switch on Codexta assistant › Save. The same link is in Settings › General under Show the assistant on your storefront.

How do I run the guided setup?

  • Who: Owner, Admin
  • Plan: any

Shopify admin › Apps › Codexta › Overview › Set up your assistant

  1. Press Set up my assistant. Codexta opens Assistant › Chat and sends “Set up my assistant” for you.
  2. The assistant shows each area — Assistant identity, Knowledge base, Voice and handover, On the storefront, Test — as done, partly done or missing, and asks How do you want to go on? Choose Go through what is missing, Review everything, Just one area or Stop here.
  3. Answer its questions. It asks which languages your shoppers write in, drafts a name, greeting and up to four starter questions, and starts the knowledge base from your Shopify policies and online-store pages.
  4. Before anything is saved, it shows you the exact text. A plain “yes” to a list of drafts approves exactly that list.
  5. In the Test step it asks a few real questions and shows which note answered each. Questions about orders, stock, prices or the cart cannot be tested from the admin: try those on your storefront.

You can skip any area, stop and come back later. Anything already done is kept. To continue or start again, type in Assistant › Chat:

  • “What is left to set up”
  • “Run the setup again”
  • “Add my shipping and returns pages to the knowledge base”

The card stays on the Overview until you press Dismiss. Dismissing is remembered for this shop in this browser. The assistant never asks for passwords or API keys.

03

Knowledge base

The knowledge base is a set of notes the assistant answers from: shipping, returns, sizing, care, contact details and anything else shoppers ask. A new shop starts with one note, How to use this knowledge base. Everyone with access can read notes; only the Owner, Admins and KB editors can change them.

How do I add a note?

  • Who: Owner, Admin, KB editor
  • Plan: any

Shopify admin › Apps › Codexta › Knowledge base

  1. Press New note.
  2. Enter a path relative to the knowledge base, for example faq/shipping.md, and press Create.
  3. Write the note. Switch between edit, split and preview to check it.
  4. Press Save.

How do I import or export notes?

  • Who: Owner, Admin, KB editor (import); anyone who can open the page (export)
  • Plan: any

Shopify admin › Apps › Codexta › Knowledge base

  1. Press Import and choose a .zip export or one or more .md files.
  2. Optionally enter a Target folder (empty = the root), for example imported/faq.
  3. Press Preview. Files are grouped as Changed, Unchanged, Not imported and Rejected. Tick Overwrite {n} changed files if you want to replace existing notes.
  4. Press Import {n} notes.

To export, press Select, tick notes and press Export selected, or press Export all.

How do I add a web page or a PDF?

  • Who: Owner, Admin, KB editor
  • Plan: any

Shopify admin › Apps › Codexta › Knowledge base › Add document (web page or PDF)

  1. Enter the page address, for example https://example.com/shipping.
  2. To include linked pages on the same site, tick Also the pages it links to on the same site and set how many (up to 50).
  3. Press Add page (or Add site). For a PDF, use the file picker instead.

The document becomes a note in the sources/ folder that the assistant can answer from.

How do I keep a web page note up to date?

  • Who: Owner, Admin, KB editor
  • Plan: any

Shopify admin › Apps › Codexta › Knowledge base › (a note added from a web page)

  1. Press Sync from source to fetch the page again. You see Synced: the page changed or Synced: no change.
  2. To sync automatically, set Sync by itself to daily or weekly.

How do I delete a note?

  • Who: Owner, Admin, KB editor
  • Plan: any

Shopify admin › Apps › Codexta › Knowledge base › (the note)

  1. Open the note and press Delete.
  2. Confirm Delete {path}? This cannot be undone.

Notes can only be deleted here. The chat does not delete notes; it merges or rewrites them instead.

How do I enrich a note?

  • Who: Owner, Admin, KB editor
  • Plan: Start, Growth, Scale

Shopify admin › Apps › Codexta › Knowledge base › (the note)

  1. Open the note and press ✦ Enrich.
  2. Codexta extracts the people, places, projects and organisations in the note into its tags.

On Lite, enrichment is not part of the plan and is refused.

How do I add to the knowledge base by chatting?

  • Who: Owner, Admin, KB editor
  • Plan: any

Shopify admin › Apps › Codexta › Assistant › Chat

  1. Ask with a clear writing word — document, record, add, write up or publish. For example:
    • “document how to …”
    • “remember this for next time”
    • “Add my shipping and returns pages to the knowledge base”
    • “sync my FAQ”
  2. When a procedure changes, ask it to update the note; it rewrites the section rather than adding a second version.

Reading your Shopify policies and pages into notes is part of the guided setup, which only the Owner and Admins can run.

What if the knowledge base is full?

  • Who: Owner, Admin, KB editor
  • Plan: limits differ by plan

Each plan allows a number of notes; your limit and how many you have are in Settings › Plan. When you reach the limit, creating, importing or adding a document stops with:

YOU SEEThe knowledge base holds {n} of the {quota} documents the {plan} plan allows. Delete a document or upgrade the plan.

Your current count is on Settings › Plan under Knowledge base notes.

04

Fix a wrong or missing answer

Every time a shopper asks something the knowledge base has nothing for, Codexta records it. The shopper is not told.

How do I answer questions the assistant missed?

  • Who: everyone sees the list; Owner, Admin and KB editor write the notes
  • Plan: any

Shopify admin › Apps › Codexta › Conversations › Unanswered

  1. Each row shows a question and how often it was asked, for example “asked 3 times in 2 conversations”. The Overview tile Questions the KB missed opens this list too.
  2. Press Write KB article.
  3. The knowledge base asks Write a knowledge base article? with the question as the title. Press Create note.
  4. Write the answer and press Save.

When the list is empty it reads Nothing unanswered. Every question found something in the knowledge base.

How do I find out why an answer was wrong?

  • Who: Owner, Admin, Support manager, Support agent, Viewer (to read)
  • Plan: any

Shopify admin › Apps › Codexta › Conversations › All › (a conversation)

  1. Find the conversation with Search (words, session or shopper id) or the Outcome, Shopper, Channel, From and To filters, then press Apply.
  2. Open it. What the assistant did lists events such as Knowledge base had no answer or Handed to a person, and the Transcript shows which tool the assistant used.
  3. Correct the note in the Knowledge base, or ask the assistant in Assistant › Chat to document the right answer.

In Settings › General, tick Name the knowledge-base article an answer came from so answers name their note.

05

Name, greeting, starter questions and languages

How do I change them by chatting?

  • Who: Owner, Admin
  • Plan: any

Shopify admin › Apps › Codexta › Assistant › Chat

  1. Type “Change the greeting and starter questions”, or run the guided setup.
  2. The assistant drafts the shop’s display name, the assistant’s name, a greeting of one or two sentences and up to four starter questions, and offers translations for each language your shoppers use.
  3. It shows the exact text and saves only after you approve.

The chat cannot change the accent colour, widget position, widget theme, What your store sells, Allow guests or chat limits. Change those in Settings › General.

How do I change them in Settings?

  • Who: Owner, Admin
  • Plan: any

Shopify admin › Apps › Codexta › Settings › General

  1. Store: Store name and What your store sells (one or two sentences the assistant keeps in mind in every chat).
  2. Assistant: Assistant name, Accent colour, Widget position, How the assistant writes, Reply window, Knowledge base language and Widget theme.
  3. Greeting and suggested questions: Greeting and Idea 1 to Idea 4. Leave the ideas empty to use the assistant’s defaults.
  4. Who can chat: Allow guests, Conversations per shopper per day and Guests’ share of monthly conversations (%).
  5. Press Save settings. You see Saved.

How do I add a language?

  • Who: Owner, Admin
  • Plan: any

Shopify admin › Apps › Codexta › Settings › General

  1. In Store or Greeting and suggested questions, choose a language from + Add language.
  2. Fill in its tab. Left empty, the default wording is used.
  3. Press Save settings.

The chat window shows the wording for the language your store is shown in, and the default in every other language. The assistant replies in the language the shopper writes in. The chat window’s own buttons and labels come in English, Croatian, Bosnian, German, French and Spanish.

06

Turn the storefront assistant on or off

The storefront assistant is the theme app embed Codexta assistant. There is no on/off switch inside Codexta itself, and the embed has no settings of its own.

How do I turn it on or off?

  • Who: anyone who can edit your theme in Shopify
  • Plan: any

Shopify admin › Online Store › Themes › Customize › App embeds

  1. Switch Codexta assistant on or off.
  2. Press Save.
  3. Open your shop and check whether the chat button is shown.

Without an active plan the assistant does not answer: shoppers are told it is not active yet, or paused because its subscription is not active. To ask guests to sign in before chatting, untick Allow guests in Settings › General.

07

Conversations, shoppers, events and assisted orders

These pages are open to the Owner, Admins, Support managers, Support agents and Viewers on every plan.

How do I choose what the Overview shows?

  • Who: Owner, Admin (pin); everyone else reads
  • Plan: any

Shopify admin › Apps › Codexta › Events

  1. Choose 7 days, 30 days or 90 days.
  2. In Assistant activity, find a tool with Search tools….
  3. Press the pin to Show on the Overview, or again to Remove from the Overview. Pins are shared with the whole team.

A new shop’s Overview shows Conversations, Resolved or assisted, Assisted revenue, Assisted orders, Handoffs to a person and Questions the KB missed.

How do I read conversations?

  • Who: Owner, Admin, Support manager, Support agent, Viewer
  • Plan: any

Shopify admin › Apps › Codexta › Conversations › All

  1. Filter by Outcome (resolved, assisted, handoff, abandoned), Shopper (guest, customer, social) or dates, and press Apply.
  2. Open a conversation to see its Summary, Shopper, Order from this conversation, What the assistant did and Transcript.

Conversations are read only. Replies from your team show as Shop staff. Conversations are kept for your plan’s retention period.

How do I find or block a shopper?

  • Who: everyone listed above (find); Owner, Admin (block, see email)
  • Plan: any

Shopify admin › Apps › Codexta › Shoppers

  1. Use Search shoppers. Press Conversations on a row to see all their chats.
  2. Press Block or Unblock. Tick Blocked only to list blocked shoppers.

A blocked shopper is told they have reached today’s limit, never that they are blocked. Blocking a guest blocks that browser; a new browser or cleared cookies is a new guest.

What counts as an assisted order?

  • Who: everyone listed above
  • Plan: any

An order counts as assisted when, in the 7 days before it was placed, the shopper’s chat added to the cart or sent a checkout link — and only once the order is paid. Orders awaiting payment are reported separately; cancelled, refunded or voided orders are not counted, and a partly refunded order counts at what is left.

08

Support console and taking over a chat

The support console is the helpdesk inside your Shopify admin. Its sections are Inbox, My dashboard, Contacts, Help center and Calls; Owners, Admins and Support managers also see Team and Reports, and Owners and Admins see Settings.

How do I switch live chat, tickets or email intake on?

  • Who: Owner, Admin
  • Plan: any

Shopify admin › Apps › Codexta › Support console › Settings › Backends

  1. Switch Tickets and incident reports, Live chat with a person or Email intake on or off. It takes a few seconds.
  2. Set live chat hours under Settings › Live chat.

The Overview’s Support card shows what is on and how many cases are open. While live chat is on, it has Pause for 1 hour, Pause until tomorrow and Resume now.

How do I take over a chat from the assistant?

  • Who: Owner, Admin, Support manager, Support agent
  • Plan: any (live chat switched on)

Shopify admin › Apps › Codexta › Support console › Inbox

  1. A shopper asks for a person, for example “I want to talk to a real person”. Their chat shows Looking for an available agent…
  2. Open the conversation in the Inbox (views include Unassigned, Mine and All open) and press Assign to me.
  3. Use Reply to write to the shopper. Their chat shows Connected to a human agent and they keep typing in the same window. Use Internal note for notes only your team sees.
  4. When done, press Resolve.

Owners and Admins are support members automatically. Other colleagues are added in the console under Settings › Members.

How do returns and tickets reach me?

  • Who: Owner, Admin
  • Plan: any

A signed-in customer can request one return per order in the chat, with photos of the item and receipt. Submitting a request does not approve it: you decide on the order in the Shopify admin. In Assistant › Chat you can ask “Any open return requests” or “Any open tickets?”; to answer, assign or close a ticket, use the Support console.

09

Back-office assistant

In Assistant › Chat, the Store assistant works with your Shopify data. KB editors can open the chat but cannot reach store data. Support managers, Support agents and Viewers do not see the Assistant page.

What can I ask?

  • Who: Owner, Admin
  • Plan: any

Shopify admin › Apps › Codexta › Assistant › Chat

  • “List this month’s orders”
  • “Show me order #1004”
  • “Which orders are not fulfilled yet”
  • “Who are my best customers”
  • “Any open return requests”

It reads orders, customers, products including drafts, your shop’s languages, currency, locations and collections, returns and support tickets. Dates are in your shop’s time zone.

How do I make a change?

  • Who: Owner, Admin
  • Plan: any

Shopify admin › Apps › Codexta › Assistant › Chat

  1. Ask for the change, for example “Change the price of the Meridian 38 to 199” or “Add this shirt as a product into the Shirts collection” with a photo attached.
  2. The assistant looks up the current value and asks a yes/no question naming the record, the old value and the new value.
  3. Answer yes to apply it. On no, nothing changes. Each change needs its own yes; one yes covers one whole product creation or edit.

It can change a customer’s note or tags; change a variant’s price and compare-at price; create a product from a photo (saved as a draft); edit a product; add a colour; put products into a collection; and create discount codes. Photos are used as sent — no editing or generated images. It recommends checking draft products and publishing them in Shopify yourself.

Not available in the chat: refunds, cancelling or editing orders, adding or removing sizes, removing colours, stock of existing products, automatic discounts and staff accounts. Do those in the Shopify admin. If the assistant reports “access denied”, the Owner needs to approve the app’s updated access in Shopify.

How do I contact Codexta from the chat?

  • Who: anyone who can open Assistant › Chat
  • Plan: any

Ask the Store assistant to contact support. It asks for an email address for the reply and sends your message. Stop ends a reply in progress and New chat starts over.

Team and roles

There is no invite button. Colleagues must be staff in your Shopify admin. The first time they open Codexta from the Shopify admin they appear as Viewer; the Owner then gives them a role.

How do I give a colleague a role?

  • Who: Owner (Admins can view the page)
  • Plan: any

Shopify admin › Apps › Codexta › Settings › Team

  1. Ask your colleague to open Codexta once from the Shopify admin.
  2. Under Members, choose their role in the dropdown. You see Role saved.
  3. To take access away, press Remove. Staff removed in Shopify lose access within about a minute.

Only the Owner changes roles. Nobody can change their own role, and the last Owner cannot be removed or demoted. The Codexta staff access panel lists every time someone from Codexta worked in your shop’s data, with the reason they gave.

11

Authoring

Authoring changes how your store’s assistant behaves — rules, wording and policies such as “never promise delivery dates” — by describing it in a chat. Changes apply to your store only.

How do I change how the assistant behaves?

  • Who: Owner, Admin
  • Plan: Scale

Shopify admin › Apps › Codexta › Assistant › Chat

  1. Start a new chat and choose Authoring at the top (next to Store assistant and Shopping assistant, a preview of what shoppers get).
  2. Describe the change. It is prepared on a separate branch, where a chat shows what your shoppers would get.
  3. It goes live only when you ask. A change to a guideline lands at once, for your store only; new tools and cards wait for Codexta review.

Track changes under Assistant › Changes (Waiting for Codexta review, Who changed what) and work with the files under Assistant › Code. Authoring cannot change permissions, plans, secrets, other stores, channels, identity or credentials.

How do I switch an assistant skill off, or take Codexta’s updates?

  • Who: Owner, Admin
  • Plan: any

Shopify admin › Apps › Codexta › Assistant › Guidelines

  1. Switch a guideline off for your store, or press Reset to go back to the default. It takes a few seconds.
  2. Under Assistant › Changes › Updates from Codexta, choose View changes, Take the update, Use Codexta’s version (remove my copy) or Keep mine.
12

Plan and usage

How do I check usage or change plan?

  • Who: Owner (change); Admin (view)
  • Plan: any

Shopify admin › Apps › Codexta › Settings › Plan

  1. See your plan, its status (for example trialing or active) and that it is billed through Shopify.
  2. The Conversations and Knowledge base notes meters show this month’s use against your limit; the bar turns red at 90%.
  3. Under Change plan, press Switch to {plan}. Shopify’s plan page opens; approve the change there.

Prices and the free trial are on Shopify’s plan page and the App Store listing; what each plan adds is on the Shopify page. When the monthly conversation limit is reached, shoppers read:

SHOPPERS SEEThis assistant has reached its conversation limit for this month. Please try again next month, or use another way to get in touch.

Guests can use 25% of the monthly conversations by default; change this under Settings › General › Who can chat.

13

Instagram and other channels

How do I connect Instagram?

  • Who: Owner, Admin
  • Plan: Growth, Scale

Shopify admin › Apps › Codexta › Settings › Integrations (page title “Connect”)

  1. Under Instagram, press Connect Instagram. Instagram opens in a new window.
  2. Sign in with your Instagram professional account, then come back to Codexta.
  3. The panel shows the account as connected and when access is valid until. Use Reconnect when it expires, or Disconnect to stop answering.

The assistant answers direct messages with the same knowledge base, product carousels and a checkout link. Replies go out within 24 hours of the customer’s message. Instagram customers place orders only after linking their shop account. Allow guests does not apply to Instagram.

On Lite and Start the page says Instagram is not part of your current plan. The same page lists other messaging channels; if one you need says it is not set up, contact support.

14

Uninstall and your data

  • Uninstalling cancels your Shopify subscription and revokes Codexta’s access to your shop.
  • 48 hours after you uninstall, all of your shop’s data is deleted. If you reinstall before then, your shop’s Codexta setup is reactivated, but you choose a plan again.
  • While installed, conversations older than your plan’s retention are deleted every night; the retention period depends on the plan. Daily statistics keep counts only.
  • Customer deletion requests from Shopify delete that shopper’s conversations, events, tickets and order links automatically.
  • Customer data requests are recorded; Codexta sends the export to the shop owner within 10 days.
  • Payments never pass through Codexta: checkout always happens in Shopify.

See the privacy policy for what is held and who processes it.

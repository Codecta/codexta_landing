Import a web page, PDF or notes

Import what you already have instead of retyping it.

Open it
  • Shopify Shopify admin › Apps › Codexta
  • WooCommerce WooCommerce › Codexta Assistant
  • Other systems The admin link in your Codexta welcome email

  1. Open Knowledge base and press Add knowledge.

  2. Pick what to bring in. The table says what each one needs.

    PickYou give
    Single web pageThe Page address, such as your FAQ page.
    Whole websiteThe Website address and how many pages to read (up to 50).
    PDFA file up to 20 MB, such as a catalogue or manual.
    NotionTick the pages you shared with the Notion integration.
    Markdown filesOne or more .md files, or a .zip of them. Press Preview first.

  3. For a web page, paste the address and press Add.

  4. For a PDF, press Choose a PDF and then Add.

  5. Open the new article under Articles to check it reads well.

Tip. Scanned PDFs without real text cannot be read. After you change a web page, press Fetch again from its source on its row, or set Refresh by itself in the editor.

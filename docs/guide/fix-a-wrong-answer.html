Fix a wrong or missing answer

Questions the assistant could not answer are saved. Answer one and it is fixed.

Open it
  • Shopify Shopify admin › Apps › Codexta
  • WooCommerce WooCommerce › Codexta Assistant
  • Other systems The admin link in your Codexta welcome email

  1. Open Conversations and choose the Unanswered tab. Each row is a question the assistant could not answer.

  2. Press Write KB article on a question.

  3. Press Create note, write the answer and press Save.

  4. If an answer was wrong, open it under All and read What the assistant did. Then correct the article.

Tip. New questions can take up to five minutes to show in the list.

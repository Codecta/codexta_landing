Add a language

Customers get your wording in their language.

Open it
  • Shopify Shopify admin › Apps › Codexta
  • WooCommerce WooCommerce › Codexta Assistant
  • Other systems The admin link in your Codexta welcome email

  1. Open Settings › General.

  2. Under Greeting and suggested questions, choose a language from + Add language.

  3. Write the greeting and ideas for that language. Left empty, the default wording is used.

  4. Under Assistant, check Chat language and set Knowledge base language to the language your articles are written in.

  5. Press Save settings.

Tip. The assistant replies in the language the customer writes in, whatever you set here.
